Multiplication Program 

A simple Python program that multiplies two numbers entered by the user.

Features
Takes two numbers as input.
Calculates their multiplication.
Displays the result.
Technologies Used
Python 3
How to Run
Install Python 3.
Download multiplication.py.
Open your terminal.
Run:
bash
python multiplication.py

Example
text
Enter first number: 5
Enter second number: 4
Multiplication result: 20
